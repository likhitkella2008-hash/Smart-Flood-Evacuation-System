Live Verification of Core Computer Science Algorithms

This interactive workbench demonstrates genuine Python implementations of Recursive Merge Sort, Iterative Binary Search, Binary Heap Priority Queue, Dijkstra's Shortest Path, and BFS/DFS Graph Traversals executed directly on flood rescue emergency data.

🔀 1. Recursive Merge Sort
Emergency Triage
Time: O(N log N) (Best/Avg/Worst)
Space: O(N) auxiliary
Type: Stable Divide & Conquer

Orders rescue requests strictly by priority category (Critical > High > Medium > Low), descending numerical score, with deterministic tie-breaking. Implemented without Python's sorted() or SQL ORDER BY.

Click "Run Merge Sort" to inspect recursive sorting on disaster telemetry.
🔍 2. Iterative Binary Search
O(log N) Lookup
Time: O(log N)
Space: O(1) in-place
Precondition: Array Sorted by ID

Locates emergency incident records by integer ID by halving the search interval at each iteration. Visualizes pointers low, mid, and high.

Enter a Request ID and click Search to trace logarithmic reduction.
⛰️ 3. Priority Queue (Binary Max-Heap)
Triage Dispatch
Push: O(log N) sift-up
Pop: O(log N) sift-down
Peek: O(1) root

Array-backed binary tree using explicit index arithmetic (parent=(i-1)//2, left=2i+1, right=2i+2) without heapq. Always extracts the most critical patient first.

Inspect pending rescue triage queue or run binary heap simulation.
🛣️ 4. Dijkstra's Algorithm
Hazard-Aware Routing
Time: O((V + E) log V)
Space: O(V)
Data Struct: Adjacency List + Min-Heap

Finds the fastest safe evacuation route across the Coimbatore road transit network. Dynamically penalizes or detours around waterlogged road segments.

➔
Select origin and destination to compute minimum distance path.

Network Analysis
BFS: FIFO Queue • Level-Order • Flood Propagation Wave
DFS: LIFO Stack • Deep Path Exploration • Evacuation Corridor
Both: O(V + E) with Visited Hash Set
